The kit you can download contains:
  src/            your program
  launch.bat / launch.sh / launch.command   double-click runners
  install.bat / install.sh     Start Menu, Desktop & app-menu shortcuts
  uninstall.bat / uninstall.sh
  build-windows.bat / build-linux.sh / build-macos.sh
                   turn it into a TRUE standalone .exe / binary / installer
  BUILD.md + README.txt        exactly what each step produces

What “standalone” means — honestly

  • Run now: launchers need the language runtime (Python, Node, JDK…) on the machine.
  • Truly standalone: run the build script once — PyInstaller / pkg / gcc / dotnet self-contained / Go static binary / jpackage produce a single executable or native installer that needs no runtime.
  • Some languages stay interpreted (SQL, R, Bash…) — the install scripts integrate them into the OS menu/PATH instead. BUILD.md tells you which is which.
