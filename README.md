## What it does

| Engine | What you get |
|---|---|
| 💬 **AI chat** | 7 model providers + federation fallback routing, persistent knowledge base, owner dashboard |
| 🎨 **BrandForge** | Full brand bibles in ~90 s: manifesto, taglines, pillars, SVG logo, palettes, typography, voice rules, applications — with compliance auditor and SVG/JSON/MD export |
| ✨ **Creative Studio — Design** | Server-rendered social graphics (YouTube/IG/Story/X/LinkedIn/cards/posters), 6 palettes, 6 background styles, logo upload, QR codes, favicon & PWA icon packs |
| 🎬 **Creative Studio — Video** | ffmpeg-powered editing in the browser: trim, speed, resize/crop-to-fit presets, caption overlays, GIF conversion, audio extraction |
| 🧊 **Creative Studio — 3D** | Live three.js 3D text forge: 5 materials, turntable recording (WebM), PNG snapshots, GLB export for Blender/Unity |
| 📎 **Registry** | SA certifications, CIPC entities and licences desk with verification trails |
| 💳 **Billing** | Pro R49 / Plus R149 / Max R249 tiers, Capitec EFT flows |
